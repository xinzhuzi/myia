# 组件安装交互重做:状态进按钮 + 排队自动装

## Goal

设置屏可选组件行交互重做:安装状态直接表现在按钮上(安装/安装中/排队中/已装/重试),单飞槽被占时点击入队自动续装,安装态壳侧化随状态广播(切屏重开不丢),护栏拒绝不再误标 transport_error。

## 背景(2026-10-13 主人报障,三轮实锤)

主人装 crawl4ai 期间连续撞上三个产品缺陷(全程地面核验在案):

1. **无排队**:组件 A 在装(单飞槽被占,crawl4ai 的 playwright chromium 钩子一跑就是几分钟到十几分钟)时点组件 B 的开关 → 壳侧单飞护栏 `Err("组件安装进行中,请稍候(同刻只装一个)")`(`pyenv_components.rs:1337`)直接弹红色错误框;A 装完后 B 不会自动装,必须手动再点。
2. **安装态丢失**:「安装中…」转圈是前端本地 React 状态(`pyenv-card.tsx` `installingComponent`),切屏重挂载/重开窗口即丢——界面上毫无安装迹象,只剩一个"点了就弹错"的开关。同刻戳未落时,连"再点 A 自己"也被 A 自己的安装挡住弹错。
3. **错误码误标**:护栏拒绝的裸字符串 Err 被前端 `asSidecarError`(`settings/api.ts:171`)统一包成 `code=transport_error`,而 `transport_error` 在仪表盘词表语义是「与核心的连接异常」——"正在忙"被报成"连接坏了"。

主人产品指令(原话):「**状态展示,按钮效果,我希望状态就表现在按钮效果上面!**」——组件行现状是 Badge「已装/未装」+ Switch 开关 + 旁挂 spinner 行三处散落,要收敛为按钮一处承载状态。

## Requirements

### R1 状态进按钮(库组件 + 未装服务组件)

组件行收敛为**单一按钮**,按状态渲染(删 Badge、删 Switch、删旁挂 spinner 行):

| 状态 | 按钮 | 可点 | 视觉 |
|------|------|------|------|
| 未装 | 「安装」 | ✅ | 主按钮 |
| 安装中 | 「安装中…」+ 内置转圈 | ❌ | 禁用 |
| 排队中 | 「排队中…」 | ❌ | 禁用 |
| 已装 | 「已装」 | ❌ | outline 成功态 |
| 上次安装失败 | 「重试安装」 | ✅ | 警告态;行内附失败原因小字 |
| 主链未配置/安装中 | 同上各态但禁用 | ❌ | title 提示先完成环境配置 |

- 状态真源 = `pyenv_get_status` 的 `components[].install_state`(R2),前端本地态只做点击后到事件到达间隙的防双击过渡。
- 已装服务组件(searxng/wechat-bridge)保持既有「启动/停止」按钮 + 健康绿点形态不变(那已是按钮态);其未装态走上表按钮化。

### R2 安装态壳侧化 + 排队自动装

- `components[]` 每条附加 `install_state: "installing" | "queued" | "error" | null`(null=不在装)与 `install_error: string | null`(失败戳原文;仅 error 态非空)。附加键向后兼容(轨B `kind` 先例:老前端宽容忽略,老壳缺省回 null)。
- 点击「安装」时单飞槽被占 → **入队**(`ComponentManager` 增 FIFO 队列),立即回执,不弹错;槽清空(装完/失败)自动取队首续装。同 id 已在装/已在队 → 幂等回执排队中,不重复入队。
- 广播时点补齐:占槽开装、入队、出队续装、装完/失败(既有)都 emit `pyenv-status-changed`——多窗口/重挂载即时同步;切屏重开靠拉取恢复指示。

### R3 护栏错误码语义修复(本档范围内)

- 「组件安装进行中」的 Err 随排队化在常规路径消失(点击=入队)。
- 剩余 Err 路径(未知 id、环境未就位)属前端先拦的结构性拒绝,不在用户可点击面。

## 边界(明确不做)

- 组件卸载:不做(既有口径,已装按钮 title 说明)。
- 排队取消:不做(排队件按钮禁用;壳重启即清空内存队列,装一半的组件重点幂等续装)。
- ErrorBox 全局 transport_error 词表(其他屏):另档处理,本档只消组件安装路径。
- 主链(pyenv 安装链)在跑时组件仍拒装:保持(envBlocked 前端先拦,文案不变)。

## Acceptance Criteria

- [ ] AC1:组件 A 安装中时,组件 B 点「安装」→ B 按钮变「排队中…」零弹错;A 装完自动开装 B(日志/事件可证)。
- [ ] AC2:安装中/排队中切走再切回设置屏(或重开窗口),指示不丢(拉取恢复)。
- [ ] AC3:crawl4ai(带 playwright 钩子)安装全程按钮显示「安装中…」;戳落 ready 后按钮变「已装」。
- [ ] AC4:人为制造失败戳(沙箱 pip 断源)→ 按钮显「重试安装」+ 失败原因;重试成功后回「已装」。
- [ ] AC5:组件行无 Switch、无「已装/未装」Badge、无旁挂 spinner;全部状态仅在按钮上。
- [ ] AC6:门禁全绿(cargo test + vitest 全量零新红);契约测试覆盖 install_state 守门(旧壳缺键宽容 → null)。
- [ ] AC7:装机包验证(换装后真机:点两个组件,第二个排队、第一个装完自动续装,按钮态全程正确)。
