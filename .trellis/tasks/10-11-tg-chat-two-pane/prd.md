# 情报视图 TG 群对话式双栏:左群列表 + 右聊天时间线

## 主人令(2026-10-11,附装机截图)

> 情报视图,这个地方,应该是左侧是群列表,点击后,展示出来右侧的群内容,而不是现在这个格式排列,UI 布局要按照 tg 的群对话方式进行布局

截图实况:3 级 TG 渠道详情(clashv8)「情报视图」= 顶部监控台大卡 + 单列窄排消息卡,两侧大片留白,既不像 TG 也不利用宽度。

## 判例与教训边界

- v7 双栏监控台(右群组左数据)在 **2 级** 交付即被推翻、v8 撤销升格为 1/2/3 级——错的是**落点粒度**,不是双栏本身。本次落点 = **3 级情报视图**,主人明令,不属翻案。
- UI 物种铁律:模仿对象 = Telegram 桌面端聊天界面(左聊天列表+右会话),布局贴近其结构性(列表行:头像徽标/名称/预览/时间/未读),不抄配色主题。
- 无头布局判例、Kestra 紫暗色、系统字体栈照旧。
