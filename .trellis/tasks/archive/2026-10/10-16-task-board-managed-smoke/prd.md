# 开放任务看板与自管 Python 装机验收

## Goal
准确列出未完成与有歧义的任务，并对已安装应用的自管 Python 资源执行真实协议验收，避免关键路径被跳过后误报全通过。

## Requirements
- 看板入口固定为 `.trellis/scripts/open_task_board.py`，原样十列，顶层任务数不含子任务。
- 排除 archive 与明确标记无需再做/统计池；未归档 completed 仍提示歧义。缺失时间、阶段等数据明确标未记录。
- 看板只读、无 Git、无进程附加、无生命周期钩子。
- 装机验收使用安装件资源与已存在解释器、临时 MYIA_HOME，不关闭现有 GUI、不联网安装运行时、不发送消息。
- 分开报告协议验收、前端资源与未覆盖 GUI/微信真实链，不允许 skip 视作成功。

## Acceptance Criteria
- [x] 十列看板包含畸形任务诊断、未归档歧义、明确排除与子任务计数测试。
- [x] 本仓看板可直接运行，不改任何任务状态。
- [x] 已安装 managed Python sidecar 可在隔离目录完成真实 RPC 验证，失败/缺失返回非零。
- [x] 保留现场运行的应用与微信，输出可复跑命令和验证边界。

## Authorization
用户“那你推进解决”已确认以上独立可做的工作；不包含 Git、归档或活进程调试附加。
