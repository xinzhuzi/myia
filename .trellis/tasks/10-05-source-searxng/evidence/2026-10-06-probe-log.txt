【坑①·colima /tmp 挂载陷阱(重要部署注记)】
最初按计划放 /tmp/searxng-probe:bind mount 源路径在 macOS /tmp,colima
默认只共享家目录,VM 内 /tmp 是本地空目录 → 容器看不到 settings.yml →
entrypoint 日志「"/etc/searxng/settings.yml" does not exist, creating
from template」→ 从镜像模板重建(无 search.formats)→ json 静默关闭 →
一切 format=json 请求 403。迁移到 ~/.searxng-probe(家目录=colima 默认
共享)后容器内 settings.yml=宿主原件,403 消失。
生产注记:任何 colima/docker-in-VM 部署,compose 目录必须放守护进程
可见的共享路径(Docker Desktop 无此问题)。

③ 三态+分页(research §4 对账)
----------------------------------------------------------------
- 缺 q+format=json → HTTP 400,body: {"error": "No query"}(预测中)

  p2 中 55 条为新 URL(7 条重叠)→ 上游语义分页+增量成立,

  注意:本构建 bing 主引擎 /config 报 paging:false(分页支持以
  引擎自报为准,google cse/naver 实测可翻)。

④ limiter 两态(research §5-2 口径定案)
----------------------------------------------------------------
默认态(false):直连零拦截,裸 curl/httpx 全通(①②③ 全程即证)。
开启态(server.limiter: true + valkey.url: valkey://valkey:6379/0):
- 裸 curl(UA=curl/x,无 Accept-Language)→ HTTP 429 "Too Many
  Requests"(17 字节纯文本)——连 /config 都拦;
- httpx 默认头(UA=python-httpx/0.28.1,无 Accept-Language)
  → HTTP 429;
- httpx 仅补 Accept-Language: zh-CN,zh;q=0.9 → HTTP 200 JSON
  (37822 bytes)——【定案】拦的是缺 Accept-Language 这一件,
  python-httpx UA 本身不拦;
- 浏览器全套头(Accept/A-L/A-E+Chrome UA)→ HTTP 200(54989 bytes)。
→ 逐条记录:2026-10-06-limiter-states.txt
